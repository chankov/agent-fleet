Add `/af-config [tab]`, the **Alt+,** shortcut and the `c` key inside the Fleet Dashboard: a full-screen Fleet configuration screen available in the Hub and in every coms peer. It shows the desired state (`.ai/agent-fleet.json`), the install record with a sha256 check of every recorded file, the overrides file by section and key with line numbers plus the values the Hub parsed at session start and its warnings, AI-state provenance with local hash state, System 1 and STT (environment variable names and presence only, never values), the fleet YAML files with LIVE marks for peers in the coms pool, damage-control rule counts and the auto-policy state, and a Hub-only Runtime tab. Rows name their origin, files edited after session start are flagged, `o` opens the selected file in a read-only viewer, and headless children receive the Overview as a notice. Pressing `i` runs the new read-only `agent-fleet inspect` verb, which composes verify (item states, findings), doctor (findings, manifest preflight), the desired state with feature availability and dependencies, and provenance validity into one JSON report; the screen shows the CLI's words in the Overview, Setup, State and AI State tabs. The CLI is resolved from the recorded `sourceRoot` or through `npx` pinned to the recorded version, spawned without a shell and bounded in time, and the bridge refuses every mutating flag unless a flow passes a confirmed intent. Changes go through the CLI only: on the Setup tab `Space`/`p` edit an unsaved draft and `a` previews `agent-fleet setup --dry-run --json`, shows the CLI's plan, re-runs the dry run on confirmation (a different plan digest means nothing is applied) and then runs `agent-fleet setup --yes --save-desired`; conflicts and migration blocks print the terminal command instead; `system1-task-triage` asks its separate data consent; a rejected desired file applies only with `--repair-config` after confirmation. On the Overrides tab `a` previews `agent-fleet configure --dry-run` as a line diff and applies with `--yes --expect-hash`. The screen itself never writes a file. `just fleet config` prints the same read-only `inspect` report in a terminal.
