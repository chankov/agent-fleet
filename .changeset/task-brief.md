Every delegated agent now receives a task brief: one file per task under the session artifacts that records the task's tier and risk, its sourced requirements, and the delegations admitted so far with their scope and status. The operator keeps an "Operator notes" section in it for decisions and open questions; the Hub preserves those notes when it refreshes the rest. A new task replaces the previous brief, and briefs are not archived with session evidence.
